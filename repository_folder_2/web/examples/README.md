# AbuLang Examples

This directory contains sample AbuLang programs for the web playground.

Examples will be added in Phase 4: UI Controls and Features (Task 17).

## Planned Examples

1. **Hello World** - Basic output with `show` command
2. **Variables** - Variable assignment and usage
3. **Loops** - For and while loop examples
4. **Functions** - Function definitions with `def`
5. **Libraries** - Using `libra` to import modules

Each example will be a separate `.abu` file that can be loaded into the playground.
